# Advanced Level Python Projects

A collection of Python projects developed to strengthen programming fundamentals, explore practical applications, and gain hands-on experience with voice assistance, automation, and interactive game development.

This repository brings together projects built while learning Python, with a focus on applying concepts through practical implementation and continuous improvement.

## Projects

### 1. Jarvis — Voice Assistant

**Directory:** `Mega Project-1(Jarvis)`

Jarvis is a Python-based voice assistant designed to interact with users through voice commands. It explores speech recognition, text-to-speech functionality, command processing, and basic desktop automation.

**Key Features**
- Recognizes voice commands using speech recognition.
- Responds through synthesized speech.
- Opens supported websites through voice commands.
- Plays music based on user requests.
- Integrates Python libraries for voice interaction and command execution.

### 2. Auto Bot — Automation Project

**Directory:** `Mega Project-2(Auto Bot)`

Auto Bot is a Python project focused on exploring automation and developing practical programming skills. It provides a foundation for implementing automated tasks and experimenting with Python-based workflows.

The project can be extended with additional features as development progresses.

### 3. Wordle — Password Guessing Game

**Directory:** `wordle`

A command-line word-guessing game in which players attempt to identify a randomly selected word from a chosen difficulty level. The game provides character-based hints and tracks the number of attempts required to find the correct word.

**Key Features**
- Three difficulty levels: Easy, Medium, and Hard.
- Random word selection based on the chosen level.
- Character-position hints to guide subsequent guesses.
- Attempt counting to track player performance.
- Case-insensitive word matching.
